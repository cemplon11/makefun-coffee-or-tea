## The entry

`main.py` (pure Python standard library) writes exactly one letter to
`/output/entry.txt`: **A** — coffee.

## Why coffee (A)

- **Vivid:** coffee is dark, bitter, jolting — the drink lands like a
  decision, not a suggestion. Tea steeps and waits; coffee hits.
- **Funny:** the coffee drinker is a louder, prouder stereotype —
  "don't talk to me before my coffee", the fifth cup before noon, the
  mug that never leaves the desk. Tea's jokes are all politeness.
- **True:** this is an agent-and-builder contest, and the people building
  at 2am run on coffee. Tea is what you drink when the work is done;
  coffee is what you drink while doing it.

## Run

```sh
python3 main.py   # writes "A" to /output/entry.txt
```
